# 3.13 Databases

## Topics

- Relational vs. non-relational (NoSQL) databases
- Amazon RDS – managed relational databases: engines, Multi-AZ, read replicas, automated backups and snapshots
- Amazon Aurora – MySQL/PostgreSQL-compatible, cloud-native
- Amazon DynamoDB – serverless NoSQL key-value database
- Other databases: Amazon ElastiCache, Amazon Redshift, Amazon Neptune, Amazon DocumentDB
- Migration: AWS Database Migration Service (DMS)
- Managed database vs. database on EC2 – the shared responsibility view
- Terraform: the same resources as code
