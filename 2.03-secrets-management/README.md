# 2.03 Secrets Management

## Topics

- Why secrets must never be hardcoded in code, AMIs, user data or Git
- AWS Secrets Manager – store, retrieve and **automatically rotate** secrets (e.g. database credentials)
- AWS Systems Manager Parameter Store – configuration values and `SecureString` parameters, free standard tier
- Secrets Manager vs. Parameter Store – when to use which
- AWS KMS – how secrets are encrypted at rest (AWS managed vs. customer managed keys)
- Accessing secrets from EC2 / Lambda / ECS with an IAM role – no keys on the server
- Auditing secret access with AWS CloudTrail
