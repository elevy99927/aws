# 2.03 Network & Application Protection, Compliance

## Topics

- Network security layers recap (VPC basics are covered in 3.02)
- Security Groups (stateful, instance level) vs. Network ACLs (stateless, subnet level)
- AWS WAF – web application firewall (layer 7)
- AWS Shield Standard vs. AWS Shield Advanced – DDoS protection
- AWS Firewall Manager
- Threat detection and posture: Amazon GuardDuty, Amazon Inspector, Amazon Macie, AWS Security Hub, Amazon Detective
- AWS Config – resource configuration compliance
- AWS Artifact – download compliance reports (SOC, PCI, ISO) and agreements
- AWS Trusted Advisor – security checks
- AWS Security Bulletins and the AWS Abuse team
