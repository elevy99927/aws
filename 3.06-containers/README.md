# 3.06 Containers: ECR, ECS & Fargate

## Topics

- Containers 101 – images, containers, registries
- "50 ways to leave your lover" – and ~10 ways to run a container on AWS: EC2 + Docker, ECS on EC2, ECS on Fargate, EKS, App Runner, Lambda (container images), Elastic Beanstalk, Lightsail containers, AWS Batch, ROSA
- Amazon ECR – private container registry: push and pull images
- Amazon ECS – clusters, task definitions, tasks and services
- AWS Fargate – serverless compute for containers (no servers to manage)
- ECS on EC2 vs. ECS on Fargate
- Exposing a service with an Application Load Balancer
- Terraform: the same resources as code
