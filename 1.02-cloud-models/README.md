# 1.02 Cloud Models

## Topics

- Service models:
  - IaaS – Infrastructure as a Service (e.g. Amazon EC2)
  - PaaS – Platform as a Service (e.g. AWS Elastic Beanstalk)
  - SaaS – Software as a Service (e.g. Amazon WorkMail, Amazon Chime)
- Who manages what in each service model
- Deployment models:
  - Public cloud (cloud-native)
  - Private cloud (on-premises)
  - Hybrid cloud (e.g. AWS Outposts, AWS Direct Connect, Site-to-Site VPN)
- Ways to interact with AWS: Management Console, AWS CLI, SDKs, Infrastructure as Code
