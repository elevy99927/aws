# 3.4 Storage: EBS, EFS & S3

## Topics

- Storage types: block vs. file vs. object
- Amazon EBS – block storage for EC2, volume types, snapshots, single-AZ
- EC2 Instance Store – ephemeral storage
- Amazon EFS – shared NFS file system, multi-AZ; Amazon FSx overview
- Amazon S3 – buckets, objects, durability (11 nines), versioning, lifecycle policies
- S3 storage classes: Standard, Intelligent-Tiering, Standard-IA, One Zone-IA, Glacier Instant/Flexible Retrieval, Glacier Deep Archive
- S3 vs. EBS vs. EFS – comparison
- S3 security – Block Public Access, bucket policies, encryption
- Hands-on: create a bucket and upload files with the CLI, view them in the Console
- Hosting a static website on S3 (website endpoint)
- AWS Storage Gateway, AWS Snow Family, AWS Backup
- Terraform: the same resources as code
