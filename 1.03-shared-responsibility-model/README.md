# 1.03 Shared Responsibility Model

## Topics

- AWS responsibility – security OF the cloud: hardware, global infrastructure, facilities, managed-service software
- Customer responsibility – security IN the cloud: data, IAM, OS and network configuration, encryption, application code
- Shared controls: patch management, configuration management, awareness and training
- How responsibility shifts by service type (EC2 vs. RDS vs. Lambda vs. S3)
- Encryption at rest and in transit – AWS KMS, AWS CloudHSM
- AWS Acceptable Use Policy and penetration testing policy
