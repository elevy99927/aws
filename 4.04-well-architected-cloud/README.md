# 4.04 Architecting in the Cloud

## Topics

- AWS Well-Architected Framework – the 6 pillars:
  - Operational Excellence
  - Security
  - Reliability
  - Performance Efficiency
  - Cost Optimization
  - Sustainability
- AWS Well-Architected Tool
- Design principles: design for failure, decouple components, automate, think parallel
- High Availability (HA) vs. Fault Tolerance vs. Disaster Recovery
- Scaling: vertical (scale up) vs. horizontal (scale out)
- Multi-AZ and multi-Region architectures
- Elastic Load Balancing (ELB) and Amazon EC2 Auto Scaling
- Decoupling with Amazon SQS and Amazon SNS
