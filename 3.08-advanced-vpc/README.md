# 3.08 Advanced VPC

## Topics

- Designing across Availability Zones – multi-AZ subnets for high availability
- Subnet tiers – public, private and isolated subnets
- NAT Gateway – outbound internet for private subnets
- VPC Endpoints – Gateway (S3, DynamoDB) and Interface (PrivateLink)
- Connecting VPCs: VPC Peering vs. **AWS Transit Gateway (TGW)**
- Hybrid connectivity: AWS Site-to-Site VPN and AWS Direct Connect
- **Amazon VPC IP Address Manager (IPAM)** – plan, allocate and track IP addresses
- VPC Flow Logs
- Terraform: the same resources as code
